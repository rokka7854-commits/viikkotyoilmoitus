# Viikkotyöilmoitus

Puhelimella ja tietokoneella käytettävä työssäoppimisen viikkotyökirja. Testiversio 5.

## Käyttö

1. Avaa opiskelijanäkymä ja täytä perustiedot, tutkinnon osat sekä jakson päivämäärät.
2. Kirjaa jaksoon kuuluvien ma–pe-päivien tehtävät. Voit valita useita tehtäviä. Oletustunnit ovat 7,5; poissaoloissa 0.
3. Kun viikon kirjaukset ovat valmiit, anna laite työpaikkaohjaajalle. Hän kirjaa viikkoarvion 1–5, palautteen ja allekirjoituksen.
4. Jaa hyväksytty raportti kouluttajalle PDF:nä tai linkkinä. Raporttiin tulevat kaikki hyväksytyt viikot.
5. Ota varmuuskopio ja valitse "Merkitse lähetetyksi ja päätä viikko", kun olet lähettänyt raportin.

Hyväksytyn viikon muokkaus poistaa hyväksynnän ja vaatii uuden allekirjoituksen.

## Tallennus ja varmuuskopio

Tiedot tallentuvat paikallisesti käyttämääsi selaimeen. Niitä ei tallenneta GitHubiin. Tallenna varmuuskopio ennen laitteen vaihtoa tai selaimen tietojen tyhjentämistä. Varmuuskopion voi palauttaa sovelluksen painikkeella.

Jaettu raporttilinkki sisältää tiedot lähetyshetkellä. Myöhemmät muutokset jaetaan uudella linkillä.

## Asennus puhelimeen

- Android: selaimen valikosta "Asenna sovellus" tai "Lisää aloitusnäyttöön".
- iPhone: avaa sovellus Safarissa ja valitse "Jaa" sekä "Lisää Koti-valikkoon".

Sovellusta voi käyttää myös selaimessa. Ensimmäisen avauksen jälkeen paikallisia kirjauksia voi tehdä ilman verkkoyhteyttä.

## GitHub Pages

Julkaistava kansio on repositorion juuri. Valitse Settings → Pages → Deploy from a branch → main → / (root).

Sovellus on tavallista HTML-, CSS- ja JavaScript-koodia. Erillistä rakennusvaihetta tai taustapalvelinta ei tarvita.
